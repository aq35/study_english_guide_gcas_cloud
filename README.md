# study_english_guide_gcas_cloud

デジタル庁「[GCASガイド](https://guide.gcas.cloud.go.jp/)」の大事な考え方を、日本語訳・英文・カタカナ(リンキング)で学ぶ教材。CSPはAWSに特化。

- [overview.md](overview.md): 大括り(8つの考え方)
- [linking-rules.md](linking-rules.md): リンキングのルール
- [practice.md](practice.md): 段階5 自分の言葉で言う練習
- [topics/aws-db-and-donts.md](topics/aws-db-and-donts.md): 補章 AWSのDBは何がいい? / やめとけ一覧
- [topics/app-dos-and-donts.md](topics/app-dos-and-donts.md): 補章 アプリの作り方 やったほうがいい / やめたほうがいい
- [topics/managed-service-practice.md](topics/managed-service-practice.md): 補章 マネージドサービス活用実践ガイドを読む
- [topics/cicd-iac-practice.md](topics/cicd-iac-practice.md): 補章 IaC と CI/CD(デリバリーパイプライン)を読む
- [topics/security-aws.md](topics/security-aws.md): 補章 セキュリティ(AWS編)を読む
- [topics/reference-architecture.md](topics/reference-architecture.md): 補章 リファレンスアーキテクチャを読む(設計全般)
- [topics/operations-modernization.md](topics/operations-modernization.md): 補章 運用モダン化実践ガイドを読む(運用の進め方)
- [principles/](principles/): 考え方ごとのフォルダ。段階を追って深掘りする

## 書き分けの約束

- 「ガイド:」: GCASガイドの原文に書かれていること
- 「推論:」: ガイドには書かれていない、筆者の推論
- 理由や短所をガイドが書いていないときは、「書かれていない」と明記する
