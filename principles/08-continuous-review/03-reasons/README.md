# 8. 継続的な見直しとコスト管理 — 段階3: なぜそう考えるのか

出典: 段階2の[原文の読み解き](../02-original/README.md)と同じ。
カタカナの `/` は息継ぎ。ルールは [linking-rules.md](../../../linking-rules.md)。
「ガイド:」はGCASガイドに書かれていること、「推論:」は筆者の推論。

## 一言で

利用料が毎月変わり、運用状況も変わるので、見直しを続ける必要があるから。

## ガイドが書いている理由

- ガイド: 「クラウドサービスの利用料が毎月変動するため」、恒常的にサイジングを見直す。
- ガイド: 月次の最適化は、「変化する運用状況を鑑みたコストの継続的な改善を目的」とし、予算を下回っていても行う。
- ガイド: 報告資料を作らずダッシュボードにするのは、「管理工数削減・リアルタイム性の観点」から。
- ガイド: 年度ごとの見直しは、「モダンアーキテクチャ化の推進やコスト削減を図る」ため。

## ガイドが書いていないこと

- 月次・半期・年度という3つの周期を、その長さにした理由。

## 推論

- 推論: 周期を重ねるのは、短い周期で細かい無駄を、長い周期で構成の大きな見直しを、それぞれ拾うため、と読める。ガイドはこの分担を明示していない。

## 理由を英語で言ってみる

- **日本語訳**: 料金は毎月変わるので、私たちは見直しを続ける。
- **English**: Fees change every month, so we keep reviewing.
- **カタカナ**: フィーズチェインジェヴリマンス / ソウウィキープリヴューイング
