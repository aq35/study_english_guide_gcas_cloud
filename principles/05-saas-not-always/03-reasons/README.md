# 5. SaaSは無条件の正解ではない — 段階3: なぜそう考えるのか

出典: 段階2の[原文の読み解き](../02-original/README.md)と同じ。
カタカナの `/` は息継ぎ。ルールは [linking-rules.md](../../../linking-rules.md)。
「ガイド:」はGCASガイドに書かれていること、「推論:」は筆者の推論。

## 一言で

SaaSは開発量を減らせるが、運用段階で利用料が高くなる場合があるから。

## ガイドが書いている理由

- ガイド: SaaS利用は「開発量の削減に繋がるため強く推奨される」。
- ガイド: ただし、「利用者数の段階的な増加が見込まれる場合等、運用段階でSaaS利用料が高額となるケース」がある。
- ガイド: だから、「ライフサイクルコストの観点から真にコスト削減効果が発現するかを慎重に評価する」。
- ガイド: 同じ外部SaaSを2〜3年使い続けているときは、市場の動向やコスト構造を検証して、再検討する。

## ガイドが書いていないこと

- 料金が高くなる仕組み(何に比例して増えるのか)。

## 推論

- 推論: SaaSの料金が、利用者数などに応じて変わる場合があるから、と考えられる。ガイドは仕組みまでは書いていない。

## 理由を英語で言ってみる

- **日本語訳**: SaaSは開発を省けるが、料金は増えうる。
- **English**: SaaS saves development, but fees can grow.
- **カタカナ**: サースセイヴズディヴェロプメント / バットフィーズキャングロウ
