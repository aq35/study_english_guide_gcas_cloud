# 1. 目指す姿 — 段階3: なぜそう考えるのか

出典: 段階2の[原文の読み解き](../02-original/README.md)と同じ。
カタカナの `/` は息継ぎ。ルールは [linking-rules.md](../../../linking-rules.md)。
「ガイド:」はGCASガイドに書かれていること、「推論:」は筆者の推論。

## 一言で

移行そのものが目的になってしまったから、「メリットを十分に得る」ことを目指す。

## ガイドが書いている理由

- ガイド: 旧方針(2018年6月に初版決定)は、クラウド第一原則に基づき、オンプレミスからクラウドへの移行を促した。
- ガイド: その反省: 「クラウドへの移行そのものが目的化されてしまい、必ずしもクラウドサービスの利用メリットを十分に享受できていないといった例も散見された」。
- ガイド: そこで、ガバメントクラウドは「スマートなクラウド利用を促すことを目的に」用意された。

## ガイドが書いていないこと

- 「散見された」例の、具体的な内容や件数。

## 推論

- 推論: 移行が目的になるとメリットが出ないので、目標を「メリットを得ること」に置き換えた、という流れに読める。ガイドの文のつなぎ直しで、ガイドが一文でこう説明しているわけではない。

## 理由を英語で言ってみる

- **日本語訳**: 私たちは、移行するだけでは足りないから、クラウドを賢く使う。
- **English**: We use the cloud smartly because moving is not enough.
- **カタカナ**: ウィユーズザクラウドスマートリー / ビコーズムーヴィングイズナリナフ
